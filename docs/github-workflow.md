# GitHub Workflow

## Pull Latest Changes

```bash
git checkout main
git pull origin main
```

## Create Branch

```bash
git checkout -b feature/example
```

## Commit

Use descriptive commit messages.

Good:

```
Added attendance dashboard
```

Bad:

```
changes
```

## Push

```bash
git push origin feature/example
```

## Pull Request Checklist

- Code builds
- Tested locally
- No console errors
- Documentation updated
